## Connection failure investigation

At initial inspection PostgreSQL (`127.0.0.1:5433`), FastAPI (`:8000`), and Vite
(`:5173`) were stopped; all connection attempts were refused. After starting
PostgreSQL and the original API, the original CareerHub search POST returned
202. The reported historical 502 could not be reproduced, so its exact historical
cause is **not established**. The baseline API queued searches asynchronously;
no live source request occurred in that POST.

The new launcher starts all application processes together and checks PostgreSQL
and migrations. A controlled API outage reproduced the frontend connection
failure. The proxy returned HTTP **503** with:

```text
API connection failed (connect ECONNREFUSED 127.0.0.1:8000).
Start ScrapLink with .venv/bin/python scripts/start_live.py;
expected API at 127.0.0.1:8000.
```

A missing worker produces a distinct 503, covered by automated tests. Database
errors return a PostgreSQL/migration-specific 503 and log the underlying exception.
No unidentified 502 is generated by this application.
